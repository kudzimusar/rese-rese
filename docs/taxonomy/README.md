# National economic taxonomy

Rese Rese uses six connected classifications: identity/party, occupation/skill/service, geography, community/group, economic offer/demand, and logistics/trust. No single tree can express all relationships.

- [Occupations, services, goods and units](occupations-commodities.md)
- [National place ontology](places.md)
- [Communities and groups](communities.md)
- [Original complete master plan](../source/RR-MASTER-01.original.md)

Canonical identifiers are immutable. Labels and dialect aliases are versioned. Unverified AI classifications are proposals, not authoritative new categories.
