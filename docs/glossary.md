# Glossary

| Term | Definition |
|---|---|
| Canonical ID | Immutable identifier independent of names, locations or third-party mapping providers |
| Party | Economic participant: person or organization |
| ProviderCapability | Claimed or independently evidenced occupation/skill |
| Skills Passport | Provider's multi-skill public profile with evidence distinctions |
| Location Passport | Human-readable canonical place reference with provenance, possibly no GPS |
| Place assertion | Source-backed claim about name, location, boundary or relationship |
| Group | Permissioned social/economic interaction space, distinct from place |
| Economic zone | Functional marketplace catchment; not necessarily government designation |
| H3 | Spatial hexagonal index, not a settlement boundary |
| Plus Code | Coordinate-based location encoding, not proof of an address |
| TrailBase | Rust-based backend using SQLite canonical data |
| MCP | Model Context Protocol, used for scoped AI tools |
| AI Action Gateway | Deterministic Rust authorization and transaction gate |
| F0/F1/F2/FX | Self-hostable/open source; open data; optional restricted free tier; forbidden commercial dependency |
| P0/P1/P2/P3 | Urgent; High; Planned; Vision |
