# Certification and release gates

| Gate | Minimum evidence |
|---|---|
| G-A | Reviewed free software/data rights; pinned Rust/TrailBase; reproducible local build; auth and canonical model proofs |
| G-B | Rural place with no coordinates; duplicate names; source provenance; self-hosted mapping and offline/text fallback |
| G-C | Multi-role providers, canonical listings, groups, quotes, ownership continuity, private visibility and transactional tests |
| G-D | English/Shona/Ndebele measured voice baselines; local AI tool authorization; numeric/place safeguards and human fallback |
| G-E | Consented rural-to-city produce, hub custody, driver services, transport evidence and audited commercial results |
| G-F | Legal/physical validation for mining, advanced GEO, 3D/AR/VR; optional future integrations under their own authority |

Every specialist return: task ID, exact commit/branch, source/migrations, commands and results, security/source rights, physical UAT if applicable, failures and rollback. Moderator issues ACCEPT, REMEDIATE or BLOCK. No Production launch from source-only evidence.
