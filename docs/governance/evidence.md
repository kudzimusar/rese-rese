# Engineering evidence and independent acceptance

A specialist return includes: task ID, parent SHA/branch, exact head SHA, modified paths, migration versions, runtime environments, commands run and actual output, test fixtures, device UAT where relevant, security and provenance impact, third-party licences, costs, rollback, open risks and explicit acceptance recommendation.

## Mandatory adversarial cases
- Two villages with identical names and one with no coordinates.
- Contradictory ward assertions; unverified road/seasonal accessibility.
- AI speech mistakes 15 for 50; assistant guesses price or village.
- Duplicate order/delivery submit and revoked-session replay.
- Private group visibility and home-coordinate privacy leak.
- Group aggregator attempting to seize supplier inventory ownership.
- No public OSM geocoder/tiles availability.
- Load contention, backup restore, delayed/offline sync.

A clean build is not physical certification. Record independent disposition and preserve evidence references.
